# NQU-ERP v0.1 Release Notes

## 版本概述

金門大學校務系統 MVP v0.1，聚焦**選課與成績管理**核心功能。

## 功能清單

### 認證與授權

- JWT 登入（學生/教師/管理員三種角色）
- RBAC 角色權限控管（`/admin/*` 限管理員、選課限學生、成績登錄限教師）

### 學生功能

| 功能 | API | 說明 |
|------|-----|------|
| 課程查詢 | `GET /api/v1/courses` | 支援 year/semester 篩選 |
| 加選 | `POST /api/v1/enrollments` | 衝堂檢查 + 名額檢查 + Transaction |
| 退選 | `DELETE /api/v1/enrollments` | 更新 enrolled_count、刪除成績記錄 |
| 課表查詢 | `GET /api/v1/students/me/schedule` | 按星期/節次排序 |
| 成績查詢 | `GET /api/v1/students/me/grades` | 含期中/期末/總成績及送交狀態 |

### 教師功能

| 功能 | API | 說明 |
|------|-----|------|
| 授課清單 | `GET /api/v1/teachers/me/courses` | 列出本學期授課 |
| 成績登錄 | `PUT /api/v1/grades/batch` | 批次設定期中/期末成績 |
| 成績鎖定 | `POST /api/v1/grades/submit` | 鎖定送交，鎖定後無法修改 |

### 管理員功能

| 功能 | API | 說明 |
|------|-----|------|
| 建立使用者 | `POST /api/v1/admin/users` | 新增學生/教師帳號 |
| 建立課程 | `POST /api/v1/admin/courses` | 新增課程含時段 |

## 技術架構

| 項目 | 技術 |
|------|------|
| 後端框架 | Rust + Axum 0.8 |
| ORM | SeaORM 2 (SQLite/PostgreSQL 可抽換) |
| 認證 | JWT (jsonwebtoken + bcrypt) |
| 資料庫遷移 | sea-orm-migration（6 tables, 3 indexes） |
| 假資料 | Python seed script (bcrypt, 可複製 `--seed 42`) |

## 資料表

| 資料表 | 說明 |
|--------|------|
| `departments` | 科系 |
| `users` | 使用者（含密碼 bcrypt hash） |
| `courses` | 課程（含學年/學期/名額） |
| `class_schedules` | 上課時段（星期 + 節次） |
| `enrollments` | 選課紀錄（status: ENROLLED/DROPPED） |
| `grades` | 成績（含期中/期末/總分/送交狀態） |

## 快速開始

```bash
# 1. 建置
cargo build

# 2. 啟動 server（自動跑 migration）
./target/debug/nqu-erp

# 3. 插入假資料（另開終端）
python3 scripts/seed.py -o scripts/seed.sql --seed 42
sqlite3 dev.db < scripts/seed.sql

# 4. 登入取得 token
curl -X POST http://localhost:8080/api/v1/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"11303001","password":"student123"}'
```

## 已知限制

- 成績鎖定後無法解鎖（需後續加入 rollback 機制）
- `enrolled_count` 使用 SeaORM model update，非 DB-level atomic
- 未實作加退選時程管理 API
- 退選後不可重新加選同一課程（需聯繫管理員）
