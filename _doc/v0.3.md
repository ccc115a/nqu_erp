# NQU-ERP v0.3 Release Notes

## 版本概述

校務系統 MVP v0.3，實作**教師端與管理員端** React 介面。本版本建立在 v0.2 學生端之上，補齊教師成績登錄與管理員帳號/課程管理流程，並新增對應後端 API。

## 後端新增 API（本版本必須）

| Method | Path | 角色 | 說明 |
|--------|------|------|------|
| GET | `/api/v1/teachers/me/courses/{course_id}/students` | Teacher | 授課課程選課學生名冊（含成績與送交狀態） |
| GET | `/api/v1/admin/users` | Admin | 帳號列表（含科系名稱） |
| GET | `/api/v1/admin/teachers` | Admin | 教師列表（供開課程式選授課教師） |
| GET | `/api/v1/admin/departments` | Admin | 科系列表（供表單下拉） |

權限防護：名冊僅限授課教師本人（`teacher_id != auth.user_id → 403`）；列表 API 僅限 Admin（Student → 403）。

## 功能清單

### 教師端

| 功能 | 頁面 | 串接 API |
|------|------|----------|
| 授課清單 | `TeacherCourses.tsx` | `GET /api/v1/teachers/me/courses` |

| 功能 | 頁面 | 串接 API |
|------|------|----------|

| 課程列表 / 開設新課程 | `AdminCourses.tsx` | `GET /api/v1/courses`、`POST /admin/courses`、`GET /admin/teachers` |

## 登入角色導向

v0.2 教師/管理員登入會被拒絕，v0.3 起依角色導向：

- STUDENT → `/courses`（課程瀏覽）
- TEACHER → `/teacher/courses`（授課清單）
- ADMIN → `/admin/users`（帳號管理）

`PrivateRoute` 支援 `roles` 屬性，角色不符時導向該角色首頁（`ROLE_HOME` in `src/roles.ts`）。

## 測試

```bash
bash test.sh              # 後端 48 tests（新增 roster / admin 列表 / 開課 / 權限 15 項）

cd frontend
bash test.sh              # Vitest 24 + Playwright E2E 10
npm test                  # 僅 Vitest（jsdom）
npx playwright test       # 僅 E2E
```

E2E 新增「教師端」（登錄成績→確認對話框→鎖定送交後輸入框禁用）與「管理員端」（新增帳號+搜尋、開設新課程）兩段描述，共 3 個測試。

### 已知 E2E 陷阱（v0.3 新增）

- `page.addInitScript` 會在**每次** `page.goto` 時重跑並清空 `localStorage` → 會把已登入使用者登出。改用 `beforeEach` 先 `goto('/login')` 再 `evaluate(() => localStorage.clear())`，僅清一次。
- `getByText`/`getByRole('cell')` 的 name 匹配不區分大小寫且為 substring：`T001` 會同時命中 `t001@nqu.edu.tw` → 需 `exact: true`；`getByPlaceholder('姓名')` 會命中「搜尋帳號 / 姓名 / 角色」→ 需 `exact: true`。

## 已知限制

- 管理員「選課時程管理（enrollment-period）」API 尚未實作（v0.4）
- 開課僅建立課程本體，尚未支援時段（class_schedules）設定
- 教師端無課表頁（v0.4 視需求）
